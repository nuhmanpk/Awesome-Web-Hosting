## 🧭 Quick Pick

Not sure where to start? Popular picks by use case:

| I want to host… | Try |
|---|---|
| A static site, portfolio or docs | [Cloudflare Pages](https://pages.cloudflare.com) · [Netlify](https://www.netlify.com) · [GitHub Pages](https://pages.github.com) |
| A Next.js / React frontend | [Vercel](https://vercel.com) · [Netlify](https://www.netlify.com) |
| A backend app or API | [Render](https://render.com) · [Firebase](https://firebase.google.com) |
| PHP or WordPress | [InfinityFree](https://infinityfree.net) · [AwardSpace](https://www.awardspace.com) |
| Serverless functions | [Cloudflare Workers](https://workers.cloudflare.com) · [AWS Lambda](https://aws.amazon.com/lambda) |
| A Discord / Telegram bot | [Bot-Hosting.net](https://bot-hosting.net) · [FadeHost](https://fadehost.com) |
| A free VPS | [Oracle Cloud](https://oracle.com/cloud) · [Google Cloud](https://cloud.google.com) |
| A site without code | [Wix](https://wix.com) · [Tilda](https://tilda.cc) |

> [!WARNING]
> Free tiers change often. Check the **[live status page](STATUS.md)** and the provider's pricing page before you commit.
