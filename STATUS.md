<details>
<summary><b>ℹ️ Status legend & how checks work</b></summary>

| Status | Meaning |
|---|---|
| 🟢 Online | Returned a 2xx response. |
| 🟡 Redirect | Final response was a 3xx redirect. |
| 🛡️ Blocked | Site answered but blocked the check: a Cloudflare challenge, or 401, 403, 406, 429, or a Cloudflare 503. Usually up. |
| 🔴 Offline | Returned another 4xx response (e.g. 404, 410). |
| ⚠️ Error | Connection failed (DNS, TLS) or a 5xx server error, including Cloudflare 52x (origin down). |
| ⏱️ Timeout | No response within 20 seconds. |
| ❔ Unknown | Response could not be classified. |

Checks run monthly and after each merged PR, with one HTTP request per homepage from a GitHub Actions runner. Failures are retried once after 5 seconds. Results can include false alarms from rate limits, maintenance or bot protection. A homepage being up does **not** confirm the free tier still exists.

</details>
